# StarUniverse MVP Checklist

## 1. First Launch（首次启动检查）

- [ ] 小程序可正常启动，无编译错误
- [ ] 欢迎页完整显示（☆ 图标 / 标题 / 副标题 / 按钮）
- [ ] 单屏布局，无滚动条

## 2. Identity（身份建立检查）

- [ ] 生日选择页 Picker 可正常弹出
- [ ] 未选择生日时按钮置灰不可点击
- [ ] 选择生日后按钮激活
- [ ] 星座结果页显示 1000ms 加载态
- [ ] 加载后正确显示星座图标和名称
- [ ] 不同生日对应正确星座

## 3. Planet（我的星球检查）

- [ ] "进入我的星球" 正确跳转到星球页
- [ ] 星球页显示 🌍 + 动态 layers
- [ ] 星座图标和名称正确
- [ ] 宇宙年龄计算正确（加入当天 = 第1天）
- [ ] 成长阶段正确显示（Seed/Sprout/Growing/Living）

## 4. Growth（成长系统检查）

- [ ] 成长里程碑随年龄变化（Day 1/3/7/15/30）
- [ ] 里程碑文案与设计一致
- [ ] 星球视觉 layers 随里程碑累积
- [ ] 新里程碑自动写入 Timeline

## 5. Daily（今日宇宙检查）

- [ ] 今日宇宙模块正确显示
- [ ] 随年龄/阶段轮换消息
- [ ] 同一天同一阶段返回一致结果

## 6. Timeline（宇宙日志检查）

- [ ] 宇宙日志入口可点击
- [ ] 首次进入有「星球诞生」种子事件
- [ ] 成长里程碑自动记录
- [ ] 事件按日期倒序排列
- [ ] 空状态显示引导文案

## 7. Interaction（互动反馈检查）

- [ ] 点击星球 🌍 显示反馈
- [ ] 反馈 2 秒后自动消失
- [ ] 离线反馈优先于触控反馈

## 8. Offline（离线成长检查）

- [ ] 首次访问无离线反馈
- [ ] 离开 1 天后返回显示归来消息
- [ ] lastVisitTime 正确更新

## 9. UI Quality（界面质量检查）

- [ ] 所有页面深色渐变背景一致
- [ ] 所有按钮使用 flexbox 居中
- [ ] 所有按钮高度统一 96rpx
- [ ] 单屏页面均无滚动
- [ ] Emoji 与文字视觉居中

## 10. Known Issues（已知问题汇总）

- [ ] KI-001 已关闭（Task-005 解决）
- [ ] KI-002 joinDate 未持久化
- [ ] KI-003 lastVisitTime 未持久化
- [ ] KI-004 Timeline 数据未持久化

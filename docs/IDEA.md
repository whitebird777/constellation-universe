## IDEA-002：宇宙回忆（Memory Moments）

### 功能简介

系统根据 Timeline 中的重要事件，在合适的时间重新展示过去的成长瞬间，让用户回顾自己的宇宙成长历程。

### 示例

- 一年前的今天，你的星球诞生了。
- 半年前，第一棵树长成了。
- 今天是你的星球来到宇宙的第365天。

### 设计原则

1. 不频繁打扰用户。
2. 仅展示具有纪念意义的事件。
3. 点击后可跳转到对应 Timeline。
4. 与 Timeline、Growth、Daily 三个系统联动。
5. 属于 V2/V3 功能，不进入 MVP。

## IDEA-003：世界没有等你（The Universe Never Waits）

### 功能简介

用户离开一段时间后，重新回到星座联盟时，发现自己的星球并没有停止变化。

宇宙会根据用户离开的时间，生成对应的离线成长记录，让用户感受到自己的星球一直在独立运行。

### 示例

用户离开7天后：

🌌 欢迎回来。

你离开的这几天里：

🌳 第一棵树已经成长完成。

🦋 第一只蝴蝶飞过了你的星球。

你的宇宙，一直在继续。

### Timeline 联动

离线期间发生的重要变化，会自动进入宇宙日志。

例如：

Day 15

🦋 第一只蝴蝶出现。

（你当时并不在。）

### 设计原则

1. 世界状态不会因为用户离开而暂停。
2. 用户回来时应该感受到惊喜，而不是压力。
3. 不采用强制签到机制，不要求用户每天登录。
4. 离线变化应该温和、自然、有生命感。
5. 属于 V2/V3 长期陪伴功能，不进入 MVP。

### IDEA-004：数据版本迁移（Data Migration）

简介：

未来用户升级小程序后，如果数据结构发生变化，系统应自动完成数据迁移，而不是要求用户重新开始。

示例：

V1：

{
  "birthday": "1993-07-10",
  "constellation": "巨蟹座"
}

V2：

{
  "profile": {
    "birthday": "1993-07-10",
    "constellation": "巨蟹座",
    "nickname": ""
  }
}

系统自动升级：

Data Version 1
        │
        ▼
Migration Engine
        │
        ▼
Data Version 2

状态：

Future Roadmap（V2/V3）。

### IDEA-006：欢迎回来（Welcome Back）。

内容如下：

当用户不是第一次进入小程序时，不要直接进入星球。
首页顶部显示一句动态欢迎语，例如：
「欢迎回来，你的星球一直在等你。」
「今天，你的宇宙又发生了一些变化。」
「距离上次见面已经 3 天了。」
点击“继续探索”后进入星球。

这不会打断流程，但会让产品更有温度。我建议把它放到 IDEA.md，标记为 V2（体验增强），等 MVP 验证完成后再考虑加入。

### IDEA-007：宇宙语录（Universe Whisper）

每天除了 Daily。

偶尔（不是每天）出现一句宇宙的话。

例如：

今天，

宇宙没有发生什么特别的事。

但你来了。

或者：

不是所有成长，

都能立刻看见。

或者：

星星不会催促谁长大。

或者：

宇宙记得每一次相遇。

注意：

它不是鸡汤。

不是励志。

不是签到奖励。

只是世界偶尔说的一句话。

一周出现一两次就够。

用户甚至会期待：

今天宇宙会不会和我说一句话？

这就是一种很轻、但很有陪伴感的体验，我建议作为 V2 功能先记录到 IDEA.md，暂时不要开发。

# Product Vision

## 产品使命

StarUniverse 是一个关于陪伴的星座联盟。

每天回来看看你的星球。不需要完成任务，不需要打败任何人，不需要证明什么。

## 设计哲学

### 陪伴，不是竞争

这里没有排行榜。没有 PVP。没有分数。你的星球只属于你。

### 等待，不是催促

我们不会发推送通知。不会告诉你"今日未签到"。不会用红点提醒你回来。你回来，是因为你想回来。

### 自然，不是奖励

宇宙不会因为你点击了某个按钮就给你奖励。世界的变化是自然的、属于它自己的。你只是幸运地见证了它。

### 安静，不是热闹

没有弹窗。没有满屏按钮。没有活动横幅。只有你的星球，和今天的宇宙。

## 为什么没有这些功能

| 没有 | 原因 |
|------|------|
| **签到** | 签到暗示"你应该每天来"。我们不想绑架你的时间。 |
| **排行榜** | 排行榜暗示"你需要比别人好"。这里不需要比较。 |
| **抽卡** | 抽卡制造的是赌博期待，不是陪伴。 |
| **体力系统** | 体力限制的是行为，不是邀请。 |
| **任务系统** | 任务暗示"你还有事没做"。宇宙不会催促你。 |
| **商城** | 我们不卖东西。至少现在不。 |
| **广告** | 永远不会。 |

## 长期目标

让每一个用户都拥有一颗属于自己的、独一无二的、会随时间自然生长的星球。

让"回来看看"成为一种习惯，而不是一种负担。

让 StarUniverse 成为移动互联网时代的一小片安静星空。

## 最高原则

> 任何功能，如果会让用户感到压力、焦虑、竞争感或被迫感，都不应该出现在 StarUniverse 中。

# StarUniverse Testing Rules

## 1. 测试目标（Testing Goal）

确保每个功能在交付前经过完整验证，用户流程可正常体验。

## 2. 功能完成标准（Definition of Done）

任何功能标记为"完成"前，必须满足以下全部条件：

- [x] 代码完成
- [x] 页面正常运行
- [x] 用户完整流程可体验
- [x] 文档同步更新

## 5. Bug 记录规范（Bug Tracking）

所有 Bug 必须记录到：

- **CHANGELOG.md** — Known Issues 章节
- 每个 Bug 分配唯一编号（KI-xxx）
- 描述清晰：问题现象 + 影响范围 + 计划修复版本

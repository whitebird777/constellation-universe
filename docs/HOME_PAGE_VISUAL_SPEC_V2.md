## 2. 星空层级（从底到顶）

| 层 | 组件 | 数量 | 视觉作用 |
|:---:|------|:---:|------|
| 1 | 深空渐变 | 1 | `radial-gradient` 从中心向外变暗 |
| 2 | 星云 | 2 | 左右各一个 CSS 径向渐变，缓慢漂移 |
| 3 | 星点 | 80 | 随机散布，独立闪烁（2-6s 周期） |
| 4 | 星尘 | 18 | 极小亮点缓慢上浮 |
| 5 | 中心光晕 | 1 | `radial-gradient` 在星球区域，呼吸动画 |
| 6 | 流星 | 2 | 18s/12s 周期交错划过 |

### 星球视觉

```
background: radial-gradient(circle at 35% 35%,
  #6B9EF5 → #3D6FD5 → #1A4AAA → #0E2D78 → #051840)

亮面在左上（35% 35%）模拟恒星光照
暗面在右下（inset box-shadow 黑色 50%）
```

## 8. 动画说明

| 动画 | 目标 | 周期 | 效果 |
|------|------|:---:|------|
| starPulse | 所有星点 | 2-6s | 缩放 + 透明度闪烁 |
| dustFloat | 所有星尘 | 8-16s | 缓慢上浮 + 水平偏移 |
| glowBreath | 中心光晕 | 6s | 缩放 0.9→1.1 |
| planetFloat | CSS 星球 | 8s | 上下 16rpx + 旋转 3° |
| ringPulse | 光环 | 5s | 缩放 + 透明度 |
| nebulaDrift | 星云 | 20-25s | 缓慢位移 |
| meteorA | 流星慢 | 18s | 左上→右下 |
| meteorB | 流星快 | 12s | 不同角度 |

## 9. 与 V1 版本的差异

| 维度 | V1 (Task-002) | V2 (本方案) |
|------|------|------|
| 背景 | 纯渐变色 | 5 层复合星空 |
| 星星 | 1 个 ☆ 字符 | 80 颗独立元素 + 18 颗星尘 |
| 星球 | 无 | CSS 渲染蓝色星球 + 光环 |
| 光晕 | 无 | 中心径向光晕呼吸 |
| 星云 | 无 | 左右双星云漂移 |
| 流星 | 无 | 双轨交错流星 |
| 卡片 | 无 | 玻璃拟态卡片 |
| 按钮 | 基础渐变 | 胶囊 + 发光 + 缩放反馈 |
| 老用户 | 无差异化 | 欢迎文案 + 按钮文案动态切换 |

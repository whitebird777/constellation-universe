# StarUniverse 游戏设计

> **Timeline 设计原则**：任何值得纪念的事情，都应该进入 Timeline；普通的世界状态变化不进入 Timeline。
>
> **Daily 设计原则**：
> 1. 每天只给用户一件最值得看的事情。
> 2. 重要变化可以提示，但真正的乐趣来自用户自己发现变化。
>
> **长期陪伴三层次**：任何长期陪伴型产品，都应该同时满足三个层次——
> 1. 今天有新鲜感（Daily）。
> 2. 未来有期待感（Growth）。
> 3. 过去有回忆感（Timeline）。
>
> **世界生命原则（Living World Principle）**：真正值得长期陪伴的世界，不是每天都有奖励，而是每天都有可能发生新的故事。
>
> **探索原则（Exploration Principle）**：探索的价值，不来自奖励，而来自未知。用户离开星球，不是为了获得东西，而是为了看见今天没有见过的宇宙。
>
> **陪伴原则（Companionship Principle）**：产品应主动欢迎用户回来，而不是仅等待用户操作。每一次重新打开产品，都应让用户感受到：世界记得他的存在。

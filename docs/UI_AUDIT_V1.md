## 3. 分项检查

### 3.1 字体规范

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| 标题字号不统一 | **A** | 欢迎 56 / 生日 48 / 星座 52 / 星球 44 / 日志 40 — 5 个页面 5 种标题尺寸，建议统一为 **48rpx** |
| 按钮字号不一致 | **B** | 欢迎/生日/星座 32rpx，星球 28rpx。建议统一 **32rpx** |
| 正文描述字号跳跃 | **B** | 欢迎 26rpx / 生日 26rpx / 星座 28rpx / 星球 22-24rpx / 日志 24-28rpx。建议统一正文 **26rpx**，辅助文字 **22rpx** |
| 星球页面文字过小 | **B** | `.section-label` 20rpx、`.section-text` 22rpx — 部分手机上可能难以阅读 |
| 字重使用良好 | ✅ | 标题 700 / 名称 600 / 按钮 500 — 三级字重体系一致 |

### 3.2 页面间距

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| 水平 padding 不一致 | **A** | 欢迎页 20rpx，其余 4 页 40rpx。欢迎页按钮因此撑满全宽。建议统一 **40rpx** |
| 底部安全区 | **B** | 仅生日页有 `padding-bottom: 80rpx` 显式处理，其他页面依赖 flex 居中。建议统一处理底部安全区 |
| 元素间距 | ✅ | 各页面内部 margin-bottom 风格一致（20-24rpx 间隔） |

### 3.3 圆角规范

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| Picker 圆角不同于卡片 | **C** | 生日页 picker `20rpx` vs Timeline 卡片 `16rpx` vs 离线反馈 `16rpx`。建议卡片类统一 **16rpx**，输入类统一 **20rpx** |
| 按钮圆角 | ✅ | 全项目按钮 `border-radius: 48rpx` — 完美统一 |
| 头像/图标圆形 | ✅ | 加载圆点 `border-radius: 50%` |

### 3.4 按钮规范

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| 按钮宽度不统一 | **A** | 欢迎页 `width: 100%`（约 710rpx），其余 `width: 560rpx`。建议统一 **560rpx** |
| 按钮高度/圆角 | ✅ | 全项目 96rpx + 48rpx — Task-UI-001 成果保持良好 |
| 按钮颜色体系 | ✅ | 主操作：`#667eea → #764ba2` 渐变，次要：`rgba(255,255,255,0.08)` — 一致 |
| 按钮禁用态 | ✅ | 生日页有灰态处理 — 当前唯一需要禁用的场景 |
| flexbox 居中 | ✅ | Task-UI-001 已全部统一 |

### 3.5 卡片规范

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| 卡片样式不一致 | **B** | Timeline `.item-card`：`padding: 20rpx 24rpx` + `background: rgba(255,255,255,0.05)`；Picker `.picker-display`：`padding: 0 36rpx` + `background: rgba(255,255,255,0.08)`。建议抽取统一 `.card` 基类 |
| 卡片透明度 | **C** | 不同卡片使用 0.05 / 0.08 / 0.1 / 0.12 四种透明度，规律不明显 |

### 3.6 Emoji / Icon 使用规范

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| Unicode 符号与 Emoji 混用 | **C** | 欢迎页 `☆`（文本符号）、星座页 `♈`（Unicode）、星球页 `🌍`（Emoji）— 在不同平台上渲染效果可能不同 |
| 辉光效果一致 | ✅ | ☆ 和 ♈ 均使用 `text-shadow` 蓝紫辉光，观感统一 |
| Emoji 尺寸合理 | ✅ | 大图标 120-180rpx，中图标 40-56rpx，小图标 22-32rpx |

### 3.7 页面视觉层级

| 问题 | 严重度 | 详情 |
|------|:---:|------|
| 生日页导航栏突兀 | **A** | 生日页是唯一未设置 `"navigationStyle": "custom"` 的页面。`app.json` 中 `navigationBarBackgroundColor: "#F6F6F6"` 会在深色背景上显示浅色导航栏，视觉断裂严重 |
| 星球页信息密度 | **B** | 7 个区块（hero + identity + growth + daily + 2 buttons + 反馈），在小屏手机上可能拥挤 |
| 页面焦点清晰 | ✅ | 每个页面都有明确的视觉重心（☆ / Picker / ♈ / 🌍 / 时间轴） |

## 5. 建议修改方案

### Phase 1：A 级修复（预计 1 个 Task）

1. **统一标题字号** — 全部页面标题改为 `48rpx`，正文字号 `26rpx`，辅助文字 `22rpx`
2. **统一页面 padding** — 全部页面水平 padding 改为 `40rpx`
3. **统一按钮宽度** — 欢迎页按钮改为 `560rpx`（与其他页面一致）
4. **生日页导航** — `index.json` 添加 `"navigationStyle": "custom"`

### Phase 2：B 级修复（预计 1 个 Task）

1. **统一按钮字号** — 星球页按钮从 28rpx 改为 32rpx
2. **抽取公共卡片样式** — `app.wxss` 新增 `.card` 基类
3. **底部安全区** — 统一 `padding-bottom: env(safe-area-inset-bottom)`

### Phase 3：C 级优化（后续迭代）

1. 统一卡片透明度体系
2. 评估 Unicode vs Emoji 渲染策略

# 星座宇宙 🌌

> 基于微信小程序 + 微信云开发的星座主题轻社交养成应用


## 项目介绍

星座宇宙是一款面向年轻用户的星座互动应用。

用户可以创建自己的星球，通过每日任务、星光系统、
星座互动、排行榜等玩法建立长期使用习惯。


## 核心功能

### 🌟 星球身份系统

- 根据生日计算星座
- 创建个人星球
- 微信身份绑定


### ⭐ 星光成长系统

- 每日任务
- 星光奖励
- 星球成长


### 🏆 排行榜系统

- 星座排行榜
- 个人星光排行榜
- 实时数据统计


### 🌌 星座互动

- 星座运势
- 星座匹配
- 星座趣谈
- 星座探索

## 开发亮点

### 1. Service 分层架构

采用：

页面层
↓
Controller
↓
Service
↓
Cloud API

降低业务耦合。


### 2. 云端排行榜系统

解决：

- 多用户数据统计
- 星座聚合
- 个人排名


### 3. 数据一致性设计

针对每日任务刷取漏洞：

采用云端状态校验机制，
避免用户删除小程序缓存后重复领取奖励。
